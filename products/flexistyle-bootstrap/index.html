FlexiStyle Bootstrap.

A robust foundation for custom Drupal sub-themes following standard Bootstrap layout and structure.

Details

FlexiStyle Bootstrap is a robust foundation for custom Drupal sub-themes. Layout and structure follow Bootstrap and the theme supports all Bootstrap versions. It is lightweight (libraries are attached per component), fully responsive and mobile-first, PWA-compatible, and uses the latest Font Awesome and Google Material icons.

Sections, colours, sizes, widths, columns and containers are all based on Bootstrap. Header, navbar, footer, Bootstrap version and maintenance-mode time settings are managed directly from the theme’s Appearance settings.

Installation

  1. Download FlexiStyle Bootstrap from Drupal.org, or install it with Composer.
  2. Install the “FlexiStyle Bootstrap” theme.
  3. Configure the theme settings.
composer require 'drupal/flexistyle_bootstrap:^1.4'

Create a Subtheme

Method 1: Creating a Subtheme Manually

  1. In the theme folder web/themes/contrib/flexistyle_bootstrap, copy the subtheme folder.
  2. Rename it (e.g. my_custom_subtheme).
  3. Open flexistyle_bootstrap_subtheme.info.yml inside it and update the name and description, keeping base theme: 'flexistyle_bootstrap': 
    name: 'My Custom Subtheme'
description: 'A custom subtheme of FlexiStyle Bootstrap.'
base theme: 'flexistyle_bootstrap'
  4. Add custom CSS in the css folder and JavaScript in the js folder.
  5. In Appearance, enable your subtheme and set it as default.

Method 2: Creating a Subtheme Using a Shell Script

  1. Go to the theme folder: cd web/themes/contrib/flexistyle_bootstrap
  2. Make the script executable: chmod +x script/subtheme.sh
  3. Run it: ./script/subtheme.sh
  4. Answer the prompts: machine name (e.g. mytheme_flexistyle_bootstrap) and theme name (e.g. Mytheme FlexiStyle Bootstrap).
  5. Go to Administration → Appearance and enable your subtheme.
cd web/themes/contrib/flexistyle_bootstrap && chmod +x script/subtheme.sh && ./script/subtheme.sh

Download Recommended Libraries

Method 1: Shell script

  1. Go to the theme folder: cd web/themes/contrib/flexistyle_bootstrap
  2. Make the script executable: chmod +x script/library.sh
  3. Run it: ./script/library.sh
  4. Answer the questions: move your Bootstrap library from vendor to libraries? download popper.js? (Yes to both).
  5. Press Enter; the download completes within seconds.
  6. In the theme settings, change the Bootstrap configuration from local to libraries.
cd web/themes/contrib/flexistyle_bootstrap && chmod +x script/library.sh && ./script/library.sh

Method 2: Manual

  1. Download Bootstrap and extract it to web/libraries/bootstrap (create the libraries folder in your root if needed; rename the extracted folder to bootstrap).
  2. Save popper.js into web/libraries/popper.js/dist.
  3. Open Appearance (/admin/appearance) and click the Settings gear for the theme.
  4. On the Bootstrap settings tab, choose Libraries in the “Bootstrap from” list.

Configuration

Open Appearance (/admin/appearance) and click Settings for the theme. You can change the header, navbar, footer, Bootstrap version and maintenance-mode time settings and styles from there.

Features

Bootstrap integration

  • Use local files, CDN or the libraries folder
  • Select the Bootstrap version (local files or CDN)

Layout

  • Fixed-width (container) or full-width (container-fluid) layouts

Global settings

  • Fonts from local files or Google Fonts
  • Font Awesome, Google Material and Bootstrap Icons
  • Global styles field for instant CSS changes without server access

Header, sidebar and footer

  • Header background and classes, normal or sticky position, three header styles, navbar background
  • Predefined sidebar block backgrounds and custom classes
  • Footer and footer-bottom backgrounds and classes

Structure and development

  • All Bootstrap classes available for layouts
  • Customizable Twig templates and pre-designed core pages
  • Ready-to-use subtheme folder; fully components-based

Performance and compatibility

  • Lightweight and high-performance
  • Accessibility-ready
  • PWA support
  • Responsive and mobile-friendly; cross-browser compatible
