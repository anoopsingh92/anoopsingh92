FlexiStyle Base Theme.

A pure CSS-based Drupal base theme built on flexbox with atomic Twig templates and per-component asset attachment.

Details

FlexiStyle is a base theme for Drupal. Header, navbar, footer and maintenance-mode time settings and styles are managed from the theme’s Appearance settings. It overrides the standard root Twig templates and attaches CSS/JS libraries per component, so unneeded libraries stay off the page.

Installation

  1. Download FlexiStyle from Drupal.org, or install it with Composer.
  2. Install the FlexiStyle theme.
  3. Configure the theme settings.
composer require 'drupal/flexi_style:^1.4'

Create a Subtheme

  1. Install the theme with Composer but don't enable it.
  2. Go to the theme folder: cd themes/contrib/flexi_style
  3. Make the script executable: chmod +x script/subtheme.sh
  4. Run sh script/subtheme.sh or ./script/subtheme.sh.
  5. Answer the prompts: machine name (e.g. mytheme_flexistyle) and theme name (e.g. Mytheme FlexiStyle).
  6. Go to Administration → Appearance and enable Mytheme FlexiStyle.
cd themes/contrib/flexi_style && chmod +x script/subtheme.sh && ./script/subtheme.sh

Configuration

Open Appearance (/admin/appearance) and click Settings for FlexiStyle. You can change the header, navbar, footer and maintenance-mode time settings and styles from there.

Features

  • Compatible with Drupal 9, 10 and 11
  • User-defined column widths; container and container-fluid layouts
  • Flexbox CSS for layout and structure; easy-to-customize Twig templates
  • Unique body classes by entity, user, role and header style
  • Global styling editor for instant changes without editing CSS files
  • Separate variables file for sitewide colours and sizes
  • Subtheme folder for creating a custom theme; overrides root Twig templates
  • Predefined Google Fonts, Font Awesome and Google Material icons
  • Custom header and footer classes; multiple header styles; header position from the UI
  • Atomic-design, components-based Twig and libraries
  • Lightweight with high Lighthouse performance, best-practice and SEO scores
  • PWA support; responsive and mobile-friendly; cross-browser compatible
  • Pre-designed 403, 404 and maintenance pages; dismissable alert messages
