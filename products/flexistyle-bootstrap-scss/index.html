FlexiStyle Bootstrap SCSS.

SCSS pipeline with variables, nesting, and mixins compiled to CSS with Gulp asset automation.

Details

FlexiStyle Bootstrap SCSS compiles all SCSS files to CSS with Gulp and works as a base theme for your own subthemes.

FlexiStyle Bootstrap SCSS builds on the FlexiStyle Bootstrap base theme and adds SCSS (variables, nesting, mixins) compiled to CSS with Gulp, which also automates asset optimisation. It is a base theme itself, so you can create custom subthemes, from small tweaks to complete overhauls, for corporate sites, blogs or e-commerce.

Requirements

  • Drupal 10 (the project page also lists Drupal 9 and 11 as compatible)[
  • Node.js for compiling SCSS
  • Gulp CLI to compile SCSS to CSS
  • Composer to install the theme
  • Command-line access to run the subtheme script and CLI tools

Installation

Install Node.js and Gulp CLI

Install Node.js from nodejs.org, then install Gulp CLI globally:

npm install -g gulp-cli

Install the theme

Install it like any contributed Drupal theme, with Composer:

composer require 'drupal/flexistyle_bootstrap_scss:^1.1'

Create a Subtheme

  1. Go to the theme folder: cd web/themes/contrib/flexistyle_bootstrap_scss[
  2. Make the script executable: chmod +x script/subtheme.sh[
  3. Run it: ./script/subtheme.sh[
  4. Enter your subtheme’s machine name and theme name, then go into the new subtheme directory.
  5. In the subtheme’s info file, replace the line project: 'flexistyle_bootstrap_scss' so it points to your source project.
  6. Install npm packages: npm install[
  7. Compile SCSS to CSS: gulp[
cd web/themes/contrib/flexistyle_bootstrap_scss && chmod +x script/subtheme.sh && ./script/subtheme.sh

Configuration

  1. Log in and go to Administration → Appearance[.
  2. Find your subtheme in the installed themes list, install it and set it as default.
  3. Click Settings next to its name to configure the theme.

Features

Bootstrap integration

  • Use local files, CDN or the libraries folder
  • Select the Bootstrap version (local files or CDN)

Layout

  • Fixed-width (container) or full-width (container-fluid) layouts

Global settings

  • Fonts from local files or Google Fonts
  • Font Awesome, Google Material and Bootstrap Icons
  • Global styles field for instant CSS changes without server access

Header, sidebar and footer

  • Header background and classes, normal or sticky position, three header styles, navbar background
  • Predefined sidebar block backgrounds and custom classes
  • Footer and footer-bottom backgrounds and classes

Structure and development

  • All Bootstrap classes available for layouts
  • Customizable Twig templates and pre-designed core pages
  • Ready-to-use subtheme folder; fully components-based

Performance and compatibility

  • Lightweight and high-performance
  • Accessibility-ready
  • PWA support
  • Responsive and mobile-friendly; cross-browser compatible
