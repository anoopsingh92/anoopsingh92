Personal portfolio and career showcase of **Anoop Singh**, Senior Software Engineer at NextOpcode Consulting LLP with 13+ years of experience specializing in front-end architecture, responsive UI/UX, decoupled CMS implementations, and custom Drupal theming (Drupal 7 → 11).

Built with semantic **HTML5**, modern **CSS3** custom properties, and lightweight **Vanilla JavaScript**, enhanced with **Lenis** smooth scrolling and **GSAP ScrollTrigger**.

---

## ✨ Features

- **⚡ Performance-First & Zero Heavy Frameworks**: Handcrafted without React, Vue, or Webpack overhead. Lightning-fast First Contentful Paint (FCP) and near-perfect Lighthouse scores.
- **🎨 Interactive Canvas & Cursor Spotlight**: Real-time canvas particle grid reactive to cursor proximity and dynamic radial glow.
- **📜 Silky Smooth Scrolling**: Integrated [Lenis](https://github.com/darkroomengineering/lenis) momentum scrolling synchronized directly with [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/) for stutter-free 60/120 FPS transitions.
- **🌓 Adaptive Theme Modes**: Seamless Dark / Light mode toggle respecting system preferences (`prefers-color-scheme`) with smooth color transitions and persistent state.
- **📱 Fully Responsive & Touch-Optimized**: Designed mobile-first with adaptive clamps (`clamp()`), safe area insets for iOS devices, and fluid typography.
- **🃏 3D Tilt Card Interaction**: Gyroscope/pointer-based 3D transform effect on project cards with dynamic specular lighting.
- **💬 Testimonials Grid**: Card-based social proof featuring recommendations from clients, architects, and technical leads with verified author profile pictures.
- **📖 In-Depth Story View (`#me`)**: Client-side hash routing toggling a comprehensive career timeline, educational background, Drupal contributions, and 16+ verified certifications.
- **♿ Accessible (WCAG)**: Keyboard navigable, high contrast ratios, reduced motion fallbacks (`prefers-reduced-motion: reduce`), and semantic ARIA attributes.

## 🚀 Local Development

To run this portfolio locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/anoopsingh92/anoopsingh92.git
   cd anoopsingh92
   ```

2. **Serve the project:**
   Because the project uses standard web technologies without a build step, you can use any static server:

   - **Using Python 3:**
     ```bash
     python3 -m http.server 3000
     ```

   - **Using Node.js (`npx serve`):**
     ```bash
     npx serve .
     ```

   - **Using VS Code:**
     Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension and click **"Go Live"**.

3. **Open in browser:**
   Navigate to `http://localhost:3000`.

## ⚙️ Content Configuration

All data arrays are located in the inline `<script>` at the bottom of `index.html`:

- **Featured Projects**: Update the `P` array (Title, URL, Description, Category, Tags).
- **All Projects (Full Story)**: Update the `LP` array (Project Name, Tech Stack, Summary, URL).
- **Testimonials**: Update the `R` array (Quote, Name, Role, Image Path). Avatar photos live in `assets/img/`.
- **Work History**: Update the `E` array with company, title, dates, and accomplishments.
- **Certifications**: Update the `CE` array with certification name, issuing organization, credential ID, and year.
- **Press & Publications**: Update the `PR` array with publisher, article title, and external link.
