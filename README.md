Personal portfolio and career showcase of **Anoop Singh**, Senior Software Engineer at NextOpcode Consulting LLP with 13+ years of experience specializing in front-end architecture, responsive UI/UX, decoupled CMS implementations, and custom Drupal theming (Drupal 7–11).

Built with semantic **HTML5**, **Modern CSS3**, and vanilla **ESNext JavaScript**, bundled and optimized with **Vite** and enhanced with **Lenis** smooth scrolling and **GSAP ScrollTrigger**.

---

## ⚡ Features

- **Performance-First Pipeline**: Bundled, tree-shaken, and minified via Vite into single CSS & JS payloads.
- **Clean Subdirectory Routing**: Native multi-page layout (`/` and `/about/`) with zero `.html` extensions.
- **Modular Partials**: Modularized `header.html` and `footer.html` statically injected at build time.
- **Interactive Canvas & Cursor Spotlight**: Real-time canvas particle grid reactive to cursor proximity.
- **Silky Smooth Scrolling**: Integrated Lenis momentum scrolling synchronized directly with GSAP ScrollTrigger.
- **Adaptive Theme Modes**: Seamless Dark / Light mode toggle respecting system preferences (`prefers-color-scheme`).
- **Fully Accessible (WCAG)**: Semantic ARIA markup, skip links, and full `prefers-reduced-motion` compliance.
